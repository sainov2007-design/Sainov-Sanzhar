## 🚀 Что делает программа?

TechMart — это **одностраничный интернет-магазин** бытовой техники, реализованный на чистом HTML, CSS и JavaScript. Проект создан как учебное задание для демонстрации работы с DOM, localStorage и анимациями CSS.

### ✅ Функциональность

| Функция | Описание |
|--------|----------|
| 🛍️ **Каталог товаров** | 16 товаров в 6 категориях с фото, ценой и рейтингом |
| 🔍 **Поиск** | Живой поиск по названию товара без перезагрузки страницы |
| 🏷️ **Фильтрация** | Кнопки-фильтры по категориям (Холодильники, ТВ, Ноутбуки и др.) |
| 🛒 **Корзина** | Боковая панель с добавлением, удалением и изменением количества |
| 💰 **Итого** | Автоматический подсчёт общей суммы заказа |
| 💾 **localStorage** | Корзина сохраняется при обновлении страницы |
| ✨ **Анимации** | Летящая иконка при добавлении, плавные переходы карточек |
| 📱 **Адаптивность** | Корректное отображение на мобильных устройствах |

## ▶️ Как запустить?

### Способ 1 — Открыть локально (самый простой)

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/techmart.git
   ```

2. Перейдите в папку проекта:
   ```bash
   cd techmart
   ```

3. Откройте файл `index.html` в любом браузере:
   - Двойной клик на файл, **ИЛИ**
   - Перетащите в браузер

> 💡 Никакого Node.js, серверов или установки пакетов — просто открываете и работает!

### Способ 2 — GitHub Pages (онлайн)

1. Перейдите в **Settings** репозитория на GitHub
2. Раздел **Pages** → Source: `Deploy from branch`
3. Ветка: `main` → Папка: `/ (root)` → нажмите **Save**
4. Через ~1 минуту сайт будет доступен по адресу:
   ```
   https://ВАШ_НИК.github.io/techmart/
   ```
